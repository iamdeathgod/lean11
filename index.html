Three steps, in this order.

Procedure

  1. Preview it

    Double-click Preview.cmd. It prints every service, app and registry value it would change, and writes nothing. If something in the list matters to you, you find out here.

  2. Apply it

    Right-click Run-Lean11.cmd and choose Run as administrator. It makes the changes, then prints what it freed and where the backup went.

  3. Undo it

    Right-click Run-Rollback.cmd. It restores services, scheduled tasks and registry values from the most recent backup, with no reinstall and no restore point required.

What stays untouched.

Schedule A
Do not modify

Most “optimisers” win a benchmark by switching off the things that keep your PC working. Lean11 does not touch any of these, at any level.

  • Windows Update service
  • Microsoft Defender
  • The Microsoft Store
  • Your files and photos
  • OneDrive contents
  • Drivers
  • Network and Wi-Fi settings
  • Your user account
Aggressive level clears the update download cache only. Windows rebuilds it.

Questions people ask.

Reference
Is it safe? Will it break Windows?

Lean11 changes settings Windows already exposes through policies, services and scheduled tasks. It does not patch system files. The riskiest work (deleting C:\Windows.old, disabling reserved storage, and DISM /ResetBase) is confined to the Aggressive level and is never run silently. Preview shows every change first, and rollback puts the settings back.

Will Windows Update still work?

Yes. The Windows Update service is never disabled at any level. At Aggressive, Lean11 clears the update download cache; Windows rebuilds it on the next update check.

Do I need to be technical?

No. Unzip, double-click Preview.cmd to read the list, then right-click Run-Lean11.cmd and choose Run as administrator. Restart when it finishes. If you are technical, read every line of the script first. It ships as plain text.

SmartScreen warned me. Is this malware?

It is an unsigned PowerShell script, and Windows warns about anything unsigned that changes system settings. That is correct behaviour for a script like this. Choose More info → Run anyway, or read the .ps1 files in Notepad first. There is no installer and no background service.

Which versions of Windows?

Windows 11, build 22000 or newer. Most tweaks also work on Windows 10, but Windows 10 is not the supported target. Lean11 detects the build and skips settings that do not exist on your version.

Can I use it on more than one PC?

Yes, on any PC you personally own or administer. The licence is PolyForm Noncommercial: free for personal use. Commercial use, including pre-installing it on machines you sell, needs a paid licence.

What if I do not like the result?

Run Run-Rollback.cmd as Administrator. It restores services, scheduled tasks and registry values from the newest backup. Removed Store apps have to be reinstalled from the Microsoft Store; rollback prints the list for you.

Is it open source?

It is source-available. The full source ships with the download and is readable, but the licence (PolyForm Noncommercial 1.0.0) restricts commercial use, so it is not OSI-approved open source. That is deliberate: it keeps the project sustainable without hiding anything from you.

Lean11 is a small, honest cleanup tool for Windows 11. Built because reinstalling Windows should not be the only way to get a clean machine.
