You have the kit.

Four steps. Preview first: it prints every change and modifies nothing. The whole job is reversible from the backup folder it leaves behind.

Setup note Free · personal licence
Before you run it
Sheet 1 of 1
L11-SET-0001

  1. Unzip it

    Extract Lean11-1.0.0.zip anywhere, such as your Desktop. Do not run it from inside the zip. There is no installer.

  2. Preview it

    Double-click Preview.cmd. It lists every service, app and setting Lean11 would change, and writes nothing. If something in the list matters to you, you find out here.

  3. Apply it

    Right-click Run-Lean11.cmd and choose Run as administrator. If SmartScreen appears, choose More info → Run anyway. It prints what it freed and where the backup went.

  4. Restart

    Reboot to finish applying the service and app changes. When you are back, compare Task Manager memory to what you saw before.

If you do not like the result

Right-click Run-Rollback.cmd and choose Run as administrator. It restores services, scheduled tasks and registry values from the newest backup-* folder. Removed Store apps have to be reinstalled from the Microsoft Store; rollback prints the list. Keep the backup folder until you are sure.
